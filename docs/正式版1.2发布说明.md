# 科务看板 1.2.1 正式版发布说明

- 版本：1.2.1
- 发布日期：2026-11-04
- 运行形态：Windows 托盘 EXE + 局域网 Web 服务
- 数据存储：主机 SQLite 数据库，集中保存

## 1.2.1 修正

- 待办只统计未来 7 天内需要办理的任务。未来 7 天以外的周期/一次性任务显示为“计划中”，不再占用待办和“我的待办”数量。
- 新增“计划中”筛选页签，日历和全部任务仍可查看未来任务。

## 1.2.0 新增

- 日历看板：按截止日期显示全科任务，支持年月切换和单日明细。
- 节假日/调休：内置 2026 年数据，支持年度同步和 JSON 导入。
- 四节点时间轴：新建任务、开始办理、提交审核、审核办结。
- 任务删除：管理员支持单条删除、勾选批量删除，回收站保留 30 天。
- 工作报送在任务归档页，支持上周/上月/自定义，导出 Word 和 Excel。
- 任务清单 Excel 增加“任务进展”列，包含时间、记录人和完整内容。
- 恢复 1.1 的任务开始时间、任务来源、管理员自审、六项默认分类。
- 托盘运行：无黑色命令行窗口，支持打开工作台、查看地址、立即备份、打开数据目录、开机自启和退出。
- 单实例运行：重复双击只打开浏览器，不会重复启动服务。

## 主要功能

- 账号密码登录，首次登录强制修改初始密码
- 管理层与普通成员的服务端权限校验
- 任务新建、编辑、开始办理、进展记录、提交审核、审核办结
- 一次性任务和按周/月/季度周期任务
- 任务来源：市委市政府、省商务厅、局领导交办、其他单位、科室自定
- 工作分类：数据报表、文字材料、调研督导、会议活动、协调对接、其他事务
- 日历、到期提醒、逾期标记、任务归档
- Word 工作报送和 Excel 明细导出
- 自动备份、手动备份、下载、快照恢复、文件恢复
- 四套界面配色

## 升级说明

1. 先退出旧版服务并保留 `data` 目录。
2. 用 1.2 EXE 替换 1.0 EXE，保持 `data` 同目录。
3. 启动后自动补充任务来源、删除标记和日历数据；已有任务不删除。
4. 升级前建议手动备份一次。

## 重要提醒

- 本系统用于局域网内部，不要将 5080 端口映射到互联网。
- 公开 GitHub 仓库只包含源代码、文档和演示数据，不包含实际 `data` 数据库。
- 初始密码仅用于首次登录，所有账号必须立即修改。
- 托盘图标在任务栏通知区；退出服务请用托盘菜单，不要直接结束进程。
