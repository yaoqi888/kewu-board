# 科务看板 1.2.1 · 首次部署说明

> 适用于开发区科内部局域网。正式版以 Windows 托盘程序运行，不再显示黑色命令行窗口。

## 一、运行环境

- Windows 10 / 11，64 位
- 建议 4GB 以上内存
- 主机与使用成员电脑处于同一局域网
- 浏览器建议 Microsoft Edge 或 Google Chrome
- 不需要安装 Python、数据库或其他软件

## 二、部署步骤

1. 将 `科务看板1.2.1` 文件夹完整解压到固定位置，例如 `D:\科务看板1.2.1`。
2. 双击 `科务看板.exe`。
3. 程序不会打开黑色命令行窗口，而是在屏幕右下角任务栏通知区显示托盘图标。
4. 首次启动会弹出说明窗口，并自动打开浏览器；如果浏览器没有自动打开，右键托盘图标选择“打开工作台”。
5. 第一次部署建议右键“以管理员身份运行” `添加防火墙规则.cmd`，允许 TCP 5080 端口。Windows 网络位置应设为“专用网络”或“域网络”。

> 不要直接在压缩包内双击运行，也不要单独移动 EXE 而留下 data 文件夹。

## 三、托盘菜单

右键任务栏通知区的“科务看板”图标：

- 打开工作台
- 查看访问地址：显示本机和局域网 URL
- 立即备份
- 打开数据目录
- 开机自动启动（勾选/取消）
- 退出服务

关闭浏览器不会停止服务。需要停止时，必须使用托盘菜单“退出服务”。

如果托盘图标被 Windows 折叠，点击任务栏右下角的 `^` 展开通知区即可看到。

## 五、局域网访问

1. 在主机上执行 `ipconfig`，记录当前网卡 IPv4 地址。
2. 托盘菜单“查看访问地址”也会显示可用地址。
3. 其他成员在浏览器打开：
   `http://主机IP:5080/`
4. 如无法访问，检查：
   - 托盘图标是否仍在运行；
   - 两台电脑是否在同一局域网；
   - Windows 防火墙是否允许 TCP 5080；
   - 主机 IP 是否变化；
   - 二级路由器是否造成跨网段隔离。

建议在路由器中为主机保留固定 IP。

## 六、1.2.1 主要功能

- 任务清单、开始时间、任务来源、工作分类筛选
- 未来 7 天以外的待办任务自动显示为“计划中”，不占用待办数量
- 四节点时间轴：新建任务、开始办理、提交审核、审核办结
- 日历看板：按截止日期显示任务，显示节假日和调休上班日
- 年度节假日手动同步/导入，不需要实时联网
- 管理员删除任务、30 天回收站
- 工作报送：上周/上月/自定义，导出 Word 报送稿和 Excel 明细
- 任务清单 Excel 导出包含“任务进展”列
- 登录、权限、周期任务、审核、备份恢复

## 七、日历与调休

正式版内置 2026 年节假日和调休数据。

- 进入“日历看板”，可切换年月；
- 每年国务院公布新一年安排后，点击“同步当年节假日”；
- 如果单位网络无法访问外网，可把年度 JSON 文件通过“导入 JSON”载入；
- 同步一次即可，不需要每天联网。

## 八、数据与备份

正式版数据位于 EXE 同目录的 `data`：

```
data\
  kewu.db          当前数据库
  backups\         自动/手动备份
  logs\            运行日志
  secret.key       登录会话密钥
```

系统默认每 24 小时自动备份一次，最多保留 40 份。也可以在“系统设置 → 数据与备份”立即备份、下载 `.db`、从快照或文件恢复。

建议每周把最新备份复制到移动硬盘或另一台电脑。升级/迁移前先关闭服务，完整保留 `data` 目录。

## 九、从 1.0 升级

1. 先通过托盘退出旧版服务。
2. 保留旧版 `data` 文件夹。
3. 用 1.2 EXE 替换旧 EXE，或解压新版本后把旧 `data` 目录放到新 EXE 旁边。
4. 启动 1.2，程序会自动补充任务来源、回收站和日历字段，不改动已有任务。
5. 首次升级建议立即做一次手动备份。

旧版默认分类如果尚未被任务使用，会替换为新的六项分类；已有任务使用的分类不会被强制删除。

## 十、安全注意事项

- 本系统是局域网内部系统，不要将 5080 端口映射到互联网。
- 请使用固定 IP 和受信任办公网络。
- 管理员账号请设置强密码，不要共用账号。
- 主机应设置 Windows 登录密码并开启锁屏。
- 如发现异常，先退出服务，保留 `data\logs\app.log`，再联系维护人员。
- 公开 GitHub 仓库仅包含程序源代码，不包含实际业务数据库；请勿把 `data` 目录上传到任何公开仓库。

## 十一、常见问题

**托盘图标找不到**  
点击任务栏右下角 `^` 展开通知区；不要重复双击 EXE，重复启动只会打开浏览器。

**其他电脑打不开**  
先确认主机本机地址 `http://127.0.0.1:5080/` 能打开，再检查防火墙、IP 和路由器是否跨网段。

**忘记密码**  
管理员进入“系统设置 → 人员与权限”，编辑成员并重置密码，会生成一次性临时密码。

**Windows 提示未知发布者**  
当前 EXE 未购买代码签名证书，看到 SmartScreen 提示时确认来源后选择“更多信息 → 仍要运行”。

**日历没有调休**  
检查当前年份是否已同步；可在日历页点击同步，或导入年度 JSON。
